## What this deck argues

DCI already teaches school, board, foundation, and competitive programmes. **DCI Enterprise** is the system of record for attendance, exams, homework, staff access, and parent WhatsApp — not a side app next to paper registers.

It maps to software that already exists:

- Campus app (Flutter, role-based): attendance, homework, daily reports, exams, PDF report cards, Excel import, audit logs
- Public website (Next.js): courses, enquiry, privacy
- Privileged server actions: staff invites, WhatsApp Cloud API
